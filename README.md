# Project Overview

This project focuses on developing an automated underwriting document workflow system for the Underwriting Operations team at Sequis Life. The automation was designed to improve operational efficiency by reducing repetitive manual activities related to PDF document processing, file organization, and workflow standardization.

The existing operational workflow required the team to manually merge PDF documents, rename files, and organize folders during daily underwriting processing activities. This manual process created several operational challenges, including inconsistent file naming structures, high risk of human error, repetitive manual work, and difficulties in handling large volumes of documents efficiently.

To address these issues, an automated workflow solution was developed using Python and Google Colab to streamline the end-to-end document processing workflow. The system automates PDF merging, file validation, file renaming, folder classification, and final output generation to support faster and more standardized underwriting operations.

The implementation of this automation system significantly improved workflow efficiency and achieved approximately **35–38× faster processing performance compared to manual operations**, helping reduce operational workload while improving consistency and scalability.
