# Underwriting Document Workflow Automation

## Overview

The **Underwriting Document Workflow Automation** project was developed for the **Underwriting Department within the Operations Directorate at PT Asuransi Jiwa Sequis Life**. The solution automates document preparation and file management activities by streamlining PDF processing, file validation, file organization, and workflow standardization to improve operational efficiency and reduce manual effort.

---

## Business Background

The Underwriting Department, as part of the Operations Directorate, processes a large volume of underwriting documents on a daily basis. These documents must be prepared, organized, and standardized before being used in underwriting assessment and policy issuance activities.

Previously, the workflow was handled manually and required multiple repetitive tasks, creating operational inefficiencies and increasing the risk of human error throughout the document preparation process.

---

## Existing Manual Process

The manual workflow consisted of several repetitive activities:

1. Collect underwriting documents from multiple sources.
2. Validate document completeness manually.
3. Merge PDF files one by one.
4. Rename documents according to predefined naming conventions.
5. Organize files into designated folders.
6. Generate final output files for operational use.

This process required significant manual effort and became increasingly difficult to manage as document volumes increased.

---

## Business Challenges

### Time-Consuming Process

Manual document preparation required substantial processing time for every underwriting batch.

### Human Error Risk

Manual merging, renaming, and classification activities increased the likelihood of operational errors.

### Inconsistent File Organization

Different naming conventions and folder structures made document management difficult and less standardized.

### Scalability Limitations

The workflow became increasingly inefficient as document volumes continued to grow.

### Operational Inefficiency

Repetitive manual activities consumed valuable operational resources and reduced productivity.

---

## Solution

A Python-based automation solution was developed to streamline the entire underwriting document workflow.

The system automatically:

* Validates input files before processing.
* Merges PDF documents automatically.
* Applies standardized naming conventions.
* Organizes documents into predefined folder structures.
* Generates structured output files.
* Integrates with Google Drive for scalable document processing.

---

## Automated Workflow

### 1. File Validation

The system validates document completeness and processing requirements before execution begins.

### 2. PDF Merge Process

Multiple underwriting documents are automatically merged into standardized output files.

### 3. Automatic File Renaming

Documents are renamed automatically using predefined business rules and naming standards.

### 4. Folder Classification

Files are organized into designated folder structures to improve consistency and accessibility.

### 5. Output Generation

The final processed documents are generated and prepared for operational use.
